# Nanoleaf

Nanoleaf 是一个本地优先、可自包含部署的 LaTeX 写作工作台，面向论文撰写、源码编辑、PDF 预览、编译诊断和 Codex 辅助修改。

当前项目包含两个平台分支：

- `windows`：Windows 版本，提供便携 Node.js、MiKTeX、局域网协作和 Windows 资源管理器集成。
- `mac`：macOS 版本，提供本地 LaTeX 写作、PDF 预览、项目管理和 macOS 原生工作流支持。

Nanoleaf 的项目文件和运行数据默认保存在本机，不上传论文内容；局域网协作需要由主机手动开启。

本项目由 hiahei 设计与维护，使用 OpenAI Codex 辅助开发。

详细操作指南和各平台启动方式请查看对应分支中的 README：

- [Windows 分支](https://github.com/hiahei/Nanoleaf/tree/windows)
- [macOS 分支](https://github.com/hiahei/Nanoleaf/tree/mac)
